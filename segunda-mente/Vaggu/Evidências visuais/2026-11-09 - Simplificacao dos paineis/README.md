Perfis Gerente e Admin com usuários fictícios `qa@example.test`, shopping fictício com dois andares e doze vagas, sensores e histórico simulados. Não foram introduzidos dados de QA no código do produto ou em banco real. Prints não comprovam produção, hardware ou Meta.

Foram conferidos popups com rascunho/aplicar/limpar/cancelar, pesquisa visível e utilizável, polling sem barra de atualização, diagnóstico/detalhes com retorno de foco, erro/recuperação, ausência de observação, carga lenta, exportação Excel/PDF, manutenção, edição por teclado/desfazer e conflito de revisão visível. Proteção de navegação do Gerente para rota Admin conferida; não substitui teste de isolamento do servidor.

Browser plugin não disponível; Playwright já instalado executado fora do isolamento com autorização. Roteiro e downloads em `ambiente.local`, ignorados pelo Git. Respostas HTTP 503/409 esperadas pertencem aos cenários negativos, sem erro inesperado de console. Movimento reduzido habilitado.
